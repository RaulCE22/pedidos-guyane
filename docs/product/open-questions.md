# Cuestiones abiertas de producto

Este documento recoge decisiones que todavía no están confirmadas. Los agentes no deben resolverlas por inferencia ni convertirlas en requisitos definitivos.

## Regla de tratamiento

Cuando una tarea dependa de una de estas respuestas, el agente debe señalar el bloqueo y pedir la decisión correspondiente antes de fijar el comportamiento. Mientras tanto, la arquitectura y los documentos deben permanecer neutrales.
