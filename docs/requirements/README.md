# Requisitos

Los requisitos describen comportamientos observables del producto y sus criterios de aceptación. El estado del requisito expresa su aprobación, no el progreso de implementación.

| ID | Requisito | Estado |
|---|---|---|
| REQ-001 | [Usuarios y comercios](REQ-001-users-and-merchants.md) | Borrador |
| REQ-002 | [Catálogo y campañas](REQ-002-products-and-campaigns.md) | Borrador |
| REQ-003 | [Creación y gestión de pedidos](REQ-003-orders.md) | Borrador |
| REQ-004 | [Historial de pedidos](REQ-004-order-history.md) | Borrador |

Los requisitos se consideran borradores hasta que el propietario del producto confirme su contenido y las decisiones pendientes que les afecten.
