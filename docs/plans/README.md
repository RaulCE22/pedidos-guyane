# Planes de implementación

Cada plan agrupa el alcance, las tareas y la evidencia de verificación de un cambio. Mantén las tareas dentro del plan; no crees un backlog paralelo.

- `active/`: planes pendientes o en curso.
- `completed/`: planes terminados y aceptados.

Cada plan contiene `plan.md` y `progress.md`. La hoja de ruta enlaza explícitamente los planes que organizan cada hito.
